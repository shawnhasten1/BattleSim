# 2024 rules coverage (SRD 5.2)

Generated by `npm run srd:2024` from `coverage.ts` and the SRD 5.2 reference data (`generated/reference.json`). Don't
edit it by hand: change a verdict in `coverage.ts` and regenerate. See PC_BUILDER_PLAN.md, Phase 0.

What the character builder can do with each 2024 class and subclass feature, feat and species trait. The builder
adds every feature whatever its verdict: one the engine can't run goes on the actor as reference text, tagged with
its gaps, never dropped and never approximated without saying so.

- **full**: runs with what the engine has today. **partial**: some of it runs; the note says what doesn't.
- **manual**: doesn't run; it's on the actor for the DM. **builder**: the builder does it (scores, proficiencies,
  skills, speed, hit points, spells, choices, pools). **info**: nothing to do in a fight.
